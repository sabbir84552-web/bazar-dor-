# 🛒 বাজার দর (Bazar Dor)

**Bazar Dor** is a modern and responsive web application built to track the daily prices of essential commodities like rice, dal, oil, vegetables, and more across various markets. It helps users easily compare prices, view market trends, and make informed purchasing decisions.

## 🚀 Technologies Used
* **Frontend:** Next.js (App Router), React, TypeScript
* **Styling:** Tailwind CSS, DaisyUI
* **Authentication:** BetterAuth (Email/Password, Google & GitHub)
* **Data Fetching:** Fetch API with Next.js caching & Suspense
* **Notifications:** React Hot Toast

## ✨ Key Features
1. **Dynamic Market Data:** Fetches and displays real-time price updates, including price changes (up/down) with intuitive visual indicators.
2. **Category-wise Filtering & Sorting:** Users can browse products by categories (e.g., vegetables, meat) and sort them by price (low to high, high to low).
3. **Comprehensive Product Details:** Protected detail pages showing minimum, maximum, and average prices alongside market-specific variations.
4. **Secure Authentication System:** Fully functional authentication via BetterAuth, supporting credentials and social logins (Google/GitHub).
5. **Profile Management:** A dedicated user profile page allowing authenticated users to view and update their personal information seamlessly.
